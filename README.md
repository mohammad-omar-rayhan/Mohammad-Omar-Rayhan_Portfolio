# Mohammad Omar Rayhan — Portfolio

A free, responsive static portfolio website built from the provided resume.

## Preview locally
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Create a public GitHub repository named `rayhan-portfolio`.
2. Upload `index.html` and `Mohammad_Omar_Rayhan_RESUME.pdf` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Wait for GitHub to publish the URL shown on the Pages settings screen. It should resemble `https://YOUR-USERNAME.github.io/rayhan-portfolio/`.

## Customize
Edit `index.html` to update text, colors, links, and sections. Replace the PDF file (keeping the filename) to update the downloadable resume.

No paid services, frameworks, or build tools required. Google Fonts is an optional external resource; fallback fonts are included.
